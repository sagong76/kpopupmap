推しのポップアップを目当てに渡韓するなら、聖水は1日がっつり使う価値のあるエリア。人気ポップアップのオープンランから、グッズ購入、カフェ休憩までの **モデルコース** をご紹介します。

## タイムライン(週末の例)

| 時間 | やること | ポイント |
|---|---|---|
| 9:30 | 聖水駅(2号線)到着 | 3・4番出口側がポップアップ密集エリア |
| 10:00 | **本命ポップアップに並ぶ** | 人気ポップアップはオープン30分〜1時間前から行列 |
| 11:00〜12:30 | 入場・グッズ購入 | 限定グッズは初日・最初の週末に売り切れがち |
| 12:30 | ランチ | ヨンムジャン通り周辺はカフェ・レストランが豊富 |
| 14:00 | 2〜3軒目のポップアップ | 午後は混雑するので、予約不要のポップアップを中心に |
| 16:00 | カフェで休憩・戦利品整理 | 写真映えするカフェが多いエリア |
| 17:00 | ソウルの森を散歩 | 水仁・盆唐線ソウルの森駅からホテルへ |

## オタ活渡韓の持ち物チェック

- [ ] **韓国でネットが使える手段**(eSIM・Wi-Fi):地図・予約確認・呼び出し通知に必須
- [ ] **T-money(交通カード)**:地下鉄移動がスムーズ
- [ ] **クレジットカード**:ほとんどのポップアップでカード決済OK
- [ ] **エコバッグ・ファイル**:グッズやポスターを折らずに持ち帰る
- [ ] **モバイルバッテリー**:並び時間中の電池切れ対策
- [ ] 冬は **カイロ**、夏は **日傘・水**(屋外で並ぶことが多い)

## 失敗しないための3つのコツ

1. **本命は朝イチに**:午後になるほど待ち時間とグッズ売り切れのリスクが増えます。
2. **最終日を避ける**:最終日は駆け込みで混雑します。マップの「本日終了」表示もチェック。
3. **予約の可否を事前確認**:韓国の電話番号が必要なアプリもあります。→ [予約アプリガイド](/ja/guide/booking-apps-for-foreigners/)

渡韓日程が決まったら、[K-POPポップアップまとめ](/ja/kpop/) で開催中のポップアップをチェックしましょう!
